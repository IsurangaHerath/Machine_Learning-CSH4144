# Machine Learning - CSH4144

This repository contains practical exercises and implementations for the **CSH4144 Machine Learning** course.

## 🛠 Setup

Install the required tools:

```bash
pip install notebook numpy pandas matplotlib scikit-learn
```

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open any `.ipynb` file and run the cells using **Shift + Enter**.

## 📚 Topics

* Data Preprocessing
* Data Visualization
* Machine Learning Algorithms
* Model Training & Evaluation

This repository is maintained for academic learning and practical Machine Learning experiments.
